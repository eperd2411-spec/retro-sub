[ BROWSER ASSIST — RECOMMENDED ]

Server YouTube bisa diblokir anti-bot. Mode ini membaca caption dari halaman YouTube yang sedang kamu buka, lalu mengirim hanya teks/timestamp caption ke RETRO SUB. Tidak perlu memasukkan password atau cookie ke server.
  1. Tambahkan bookmark di bawah ke bookmark bar browser (drag link ke bookmark bar).
  2. Buka video YouTube yang ingin diambil caption-nya.
  3. Klik bookmark RETRO SUB EXTRACT.
  4. Pilih bahasa caption. Hasil otomatis masuk ke jendela RETRO SUB.
